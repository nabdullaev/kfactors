# kfactors

**kfactors** is a Python library for estimating the number of latent factors in financial panels and evaluating factor-based portfolio strategies.

The library provides:

- Factor-number selection rules and estimators.
- Portfolio strategies, including Minimum Variance and Tangency PCA.
- Walk-forward backtesting.
- Performance evaluation and statistical diagnostics.
- Baseline methods for comparison.
